### Manage bans across Telegram communities

> Communities let you ban a user from every chat of a Telegram community Sophie is in with a single command, and keep the ban enforced for users who post or join later.

## Available commands


### Only admins

| Commands | Arguments | Description | Remarks |
| --- | --- | --- | --- |
| `/cban` `/scban` | `<User>` `<?Reason>` | Ban a user from the whole community. |  |
| `/uncban` `/cunban` | `<User>` | Unban a user from the whole community. |  |

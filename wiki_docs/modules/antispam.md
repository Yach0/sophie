### Protect groups with built-in and third-party anti-spam.


## Available commands


### Only admins

| Commands | Arguments | Description | Remarks |
| --- | --- | --- | --- |
| `/antispam` | - | Show anti-spam status and active services for this chat. |  |
| `/antispam` | `<Mode>` | Set anti-spam mode for this chat (off, normal, or strict). |  |
| `/antispam_3party` | `<New state>` | Turn third-party anti-spam sources on or off for this chat. |  |
| `/antispam_trust` | `<Duration>` | Exempt chat members from anti-spam after a membership duration (or off). |  |

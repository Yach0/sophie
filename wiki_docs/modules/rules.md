### Set and display chat rules

> Allows administrators to set rules for their chats. \
> Users can view the rules at any time using the rules command.

## Available commands


### Commands

| Commands | Arguments | Description | Remarks |
| --- | --- | --- | --- |
| `/rules` | - | Gets chat rules | *Disable-able* |
{.card-view-on-mobile}

### Only admins

| Commands | Arguments | Description | Remarks |
| --- | --- | --- | --- |
| `/setrules` | `<Content>` | Sets chat rules | *Only in groups* |
| `/resetrules` | - | Resets chat rules to default settings. | *Only in groups* |
{.card-view-on-mobile}
